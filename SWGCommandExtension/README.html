Discord Chat Bridge — Player Guide

This guide is for players running the game extension (SWGCommandExtension.dll). It covers everything you can put in your DiscordBridge.ini settings file. If you are the person hosting the relay, see the separate guide in the Relay folder.

With the bridge running:

  • Your guild chat shows up in a Discord channel.
  • Messages typed in that Discord channel show up in guild chat in-game.
  • World boss announcements from the game server are posted to Discord as colour-coded alerts — green for PvE, red for PvP.

Getting started

Create a file called DiscordBridge.ini in the same folder as SWGCommandExtension.dll. Only three settings are required:

[DiscordBridge]
enabled=1
endpoint=https://your-relay-address/relay
key=paste-the-key-you-were-given-here

The web address and the key come from whoever runs the relay for your guild (the "operator"). Everything else below is optional.

All settings

SettingNormallyWhat it does
enabled1 1 starts the bridge automatically when the game loads. 0 keeps it off until you type /emu discord on.
endpoint(required) The relay's web address — the operator will tell you what it is. It should start with https://.
key(required) The access key handed out by the operator. The bridge does nothing while this is empty. Treat it like a password.
client_id(blank) How you appear in the operator's logs. Left blank, an anonymous code unique to your computer is used instead — never your computer's actual name.
character(blank) Your character's name, purely as a friendly label in the operator's logs and the bot's "who's online" replies. Fine to leave blank.
galaxy(blank) The server you play on — another optional label, same as above.
channel_type9 The number the game uses internally for guild chat. Leave it alone unless your guild chat is not being relayed — in that case type /emu discord types in-game, find the number next to your guild lines, and put it here. Plain numbers only; a typo stops the bridge with a message rather than guessing.
allow_http0 A safety catch. Addresses starting http:// (without the s) are refused because your key would travel unprotected. Only set this to 1 for testing on your own machine.
stage21 Whether your game helps carry messages from Discord into guild chat. Set to 0 to opt out — your chat still goes to Discord, and Discord replies still reach the guild through other members' games.
alerts1 Whether your game helps relay world boss announcements. Set to 0 to opt out; guild chat relaying is unaffected.
alert_channel_types5,11 Which in-game message channels are watched for boss announcements (5 and 11 are the system and quest message channels). Setting this replaces the normal list rather than adding to it. Numbers separated by commas, up to 16 of them.
alert_tags[PvE World Boss],[PvP World Boss] The phrases that mark a line as a boss announcement. A line only counts when it starts with one of these (capital letters don't matter). Setting this replaces the normal list. Separate entries with commas, up to 16.
What leaves your machine: your guild chat, and — on the watched channels — only lines that start with one of the alert phrases. Your mission updates, loot messages and everything else personal on those channels never leave your computer. Because a line typed by a player always arrives with their name in front, nobody can fake a boss announcement by typing one.
If you mistype an alert setting (say, a word where a channel number should be), the bridge turns the alerts feature off and tells you why in /emu discord status — guild chat keeps working while you fix it.

Handy in-game commands

/emu discord onTurns the bridge on and re-reads the ini file, so edits apply without restarting the game.
/emu discord offTurns the bridge off, both directions.
/emu discord statusShows whether the bridge is running, what it has sent, and spells out anything that's wrong (a missing key, a mistyped setting, and so on).
/emu discord testSends a harmless test line so you can check the connection without saying anything in guild chat.
/emu discord pollAsks the relay for waiting Discord messages right now instead of at the next scheduled check.
/emu discord typesLists the chat channel numbers your game has seen — useful for checking channel_type and alert_channel_types.
Two things to be careful of:
  • Your key is like a password — don't post or share it.
  • Comments in the file (lines starting with ;) must be on their own line. Writing a note at the end of a setting line breaks that setting.
